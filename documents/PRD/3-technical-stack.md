# 3. Technical Stack
- **Frontend:** React 18, TypeScript, Material UI 6+ (Styled Components).
- **State Management:** Custom StoreManager with API Sync and Persistence.
- **Backend:** Node.js (Express), TypeScript (REST API).
- **Database:** MongoDB Atlas (Document DB) for persistent "Master Recipes."
- **3D/2D Graphics:** Three.js (React Three Fiber), SVG Parametric Engine.
- **Architecture:** Enterprise Feature-Based Structure (Udacity Standard).
