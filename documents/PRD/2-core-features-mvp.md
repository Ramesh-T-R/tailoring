# 2. Core Features (MVP)

## 2.1 Project Management Dashboard
- **Feature:** A central "Guild Admin" interface.
- **Requirement:** List, open, and create bespoke projects.
- **Requirement:** Professional header with user branding ("Master Ramesh").

## 2.2 Scientific Measurement System
- **Feature:** Precision-driven data entry.
- **Requirement:** Capture Gender, Height, Chest, Waist, Hips, Shoulder Width, Arm Length, and Neck Circumference.
- **UI Pattern:** "Parametric Sliders" for high-precision tactile adjustment.

## 2.3 Parametric Geometric Engine ("Digital Chalk")
- **Feature:** Vector-based pattern planning with "Ripple" logic.
- **Requirement:** Changes in customer measurements must automatically recalculate the 2D vector points of pattern pieces (e.g., Shirt Front, Back Panel).
- **Requirement:** Maintain structural integrity through geometric constraints.

## 2.4 3D Pre-Visualizer
- **Feature:** "Digital Dress Rehearsal."
- **Requirement:** Render a floating 3D dress (Formal Shirt, Skirt, etc.) that scales dynamically with measurements.
- **Requirement:** Fabric-Aware Rendering: Adjust color and shaders (roughness/clearcoat) based on material selection (Silk, Denim, Linen).

## 2.5 Stitch Toolkit ("Master Consultant")
- **Feature:** Automated technical expertise.
- **Requirement:** Recommend specific needle types, presser feet, and thread based on fabric weight and stretch.
- **Requirement:** "Completeness Check": Identify if essential pieces (like collar linings or cuffs) are missing from the cutting plan.

## 2.6 Version Control System
- **Feature:** "Git-for-Garments."
- **Requirement:** Capture immutable snapshots of the project state after every significant change.
- **Requirement:** Provide professional "Undo" capability to revert geometric or material adjustments.

## 2.7 Configuration Management
- **Feature:** Technical Atelier Settings.
- **Measurement Types:** CRUD interface for defining custom measurement parameters.
- **Size Charts:** CRUD interface for defining standardized size tables (S, M, L, etc.) with configurable units (cm/in).
- **Dress Types:** CRUD interface for defining standardized garment blueprints.
- **Design category:** CRUD interface for modular pattern component definitions.
